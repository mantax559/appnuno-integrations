# AppNuno for WooCommerce 8.x

## Installation

1. In WordPress admin, go to **Plugins → Add New Plugin → Upload Plugin** and upload `appnuno-woocommerce-8.x.zip`.
2. Click **Install Now**, then **Activate**. WooCommerce must already be installed and active.
3. Open **AppNuno** in the admin menu and configure the navigation.

The plugin stores its settings in `module_appnuno_status` and `module_appnuno_config`. Deleting the plugin removes both options.

## Requirements

- WordPress 6.2 or newer
- WooCommerce 8.x
- PHP 7.3 or newer

## Update

1. Back up your store files and database.
2. Upload the new `appnuno-woocommerce-8.x.zip` from **Plugins → Add New Plugin → Upload Plugin** and replace the current version when WordPress asks.
3. Open **AppNuno** and confirm the saved navigation.

Do not delete the plugin before updating. Deleting it removes the saved settings.
