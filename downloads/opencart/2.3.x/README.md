# AppNuno for OpenCart 2.3.x

## Installation

1. In OpenCart admin, go to **Extensions → Extension Installer** and upload `appnuno-opencart-2.3.x.ocmod.zip`.
2. Go to **Extensions → Modifications** and click **Refresh**.
3. Go to **Extensions → Extensions → Modules**.
4. Find **AppNuno Native Navigation**, click **Install**, then **Edit** to configure the module.

For an existing installation, upload the new archive and refresh modifications. Do not uninstall the module when upgrading, as this removes its saved settings.
